# 27-Day Project Roadmap

This roadmap is a guide, not a requirement to rush. Keep learning one day at a time and commit meaningful progress regularly.

| Day | Learning focus | Project deliverable |
|---:|---|---|
| 1 | Python variables and data types | Basic project setup and sample calculations |
| 2 | Lists, dictionaries and arithmetic | Small multi-product sales example |
| 3 | Conditions and comparisons | Simple sales/business rules |
| 4 | Loops | Iterate over products and transactions |
| 5 | Functions | Reusable sales calculations |
| 6 | Python revision and practice | Refactor early exercises |
| 7 | Files and paths | Locate and load project files |
| 8 | Pandas introduction | Create and inspect DataFrames |
| 9 | Reading Excel/CSV | Load Online Retail workbook |
| 10 | DataFrame selection and filtering | Explore columns and subsets |
| 11 | Missing values | Identify missing data |
| 12 | Data cleaning | Handle missing values and duplicates |
| 13 | Pandas functions and aggregation practice | Basic descriptive statistics |
| 14 | GroupBy and aggregation | Product/customer summaries |
| 15 | Exploratory data analysis | Initial business questions and findings |
| 16 | Customer-level metrics | Prepare customer-level RFM inputs |
| 17 | RFM scoring and segmentation | Validate RFM scores and segment rules |
| 18 | RFM interpretation | Profile and compare customer segments |
| 19 | Sales trend analysis | Monthly/daily revenue trends |
| 20 | Product performance | Top/bottom products and revenue contribution |
| 21 | Country/geographic analysis | Country-level customer and sales summary |
| 22 | Matplotlib | First clear project charts |
| 23 | Seaborn and chart refinement | Segment and sales visualizations |
| 24 | Business insights | Translate analysis into business recommendations |
| 25 | Dashboard/report planning | Select KPIs and assemble report/dashboard |
| 26 | Testing and project cleanup | Validate calculations, paths, and reproducibility |
| 27 | Final presentation and GitHub polish | Final report, README, screenshots, and release |

## Suggested final deliverables

1. Reproducible Python source code in `src/`.
2. Learning/exploration notebooks in `notebooks/`.
3. Cleaned data generated locally (not necessarily committed).
4. Customer RFM table and segment summary.
5. Sales, product, customer and country analyses.
6. Clear charts in `reports/figures/`.
7. Final business report with actionable recommendations.
8. GitHub README with project overview, setup, methodology, results, and screenshots.
9. Tests for core calculations and segmentation rules.

## Good Git habits while learning

- Commit after a meaningful milestone, not after every tiny edit.
- Use messages such as `day-17: add rfm scoring practice` or `day-20: add product revenue analysis`.
- Run `git status` before every commit.
- Keep raw datasets, virtual environments, secrets, and large generated files out of Git.
- Never overwrite your existing Day 1–17 scripts when merging this scaffold. Move or adapt them deliberately.
